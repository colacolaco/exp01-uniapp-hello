# 提交说明：把工程推到 Gitee / GitHub

本地仓库已初始化并完成提交（见 `git log`）。下面只差"推到远端 + 回填链接"这两步。

## 一、先在网页端建空仓库

- Gitee：https://gitee.com/projects/new
- GitHub：https://github.com/new

> ⚠️ 建仓时**不要**勾选 "初始化 README / .gitignore / License"，要一个**空仓库**，否则推送会因历史不一致被拒。

仓库名建议：`exp01-uniapp-hello`

## 二、推送（HTTPS 方式，最简单）

```bash
cd "C:\Users\HP\Desktop\移动应用开发课程\exp01-uniapp-hello"

# 若推 Gitee（把 <你的用户名> 换成你的）
git remote add origin https://gitee.com/<你的用户名>/exp01-uniapp-hello.git
git push -u origin main

# 若推 GitHub
git remote add origin https://github.com/<你的用户名>/exp01-uniapp-hello.git
git push -u origin main
```

首次推送会弹窗要求登录：Gitee 用账号密码/私人令牌；GitHub 已在 2021 年后**不再支持密码**，需用 Personal Access Token（Settings → Developer settings → Personal access tokens → 勾选 `repo`）当密码粘贴。

## 三、推送（SSH 方式，免每次输入）

```bash
# 1. 生成密钥（一路回车）
ssh-keygen -t ed25519 -C "你的邮箱"

# 2. 复制公钥内容
type $env:USERPROFILE\.ssh\id_ed25519.pub

# 3. 粘贴到：Gitee「设置 → SSH公钥」/ GitHub「Settings → SSH and GPG keys」
# 4. 验证并推送
ssh -T git@gitee.com          # 或 ssh -T git@github.com
git remote set-url origin git@gitee.com:<你的用户名>/exp01-uniapp-hello.git
git push -u origin main
```

## 四、同时推两个平台（可选）

```bash
git remote add gitee  https://gitee.com/<用户名>/exp01-uniapp-hello.git
git remote add github https://github.com/<用户名>/exp01-uniapp-hello.git

git push -u gitee main
git push -u github main
```

拉取时用 `git remote -v` 查看别名，推送时显式指定 `git push gitee main` / `git push github main`。

## 五、常见报错

| 报错 | 原因 | 解决 |
| --- | --- | --- |
| `remote: HTTP Basic: Access denied` | 密码错误或未用令牌 | Gitee 用私人令牌，GitHub 用 PAT |
| `Updates were rejected because the remote contains work...` | 远端非空（建仓时勾了 README） | `git pull --rebase origin main` 后再 `git push` |
| `fatal: remote origin already exists` | 已存在同名远端 | `git remote set-url origin <新地址>` |
| `Permission denied (publickey)` | 公钥未加到平台 | 重新粘贴 `id_ed25519.pub` 全部内容 |
| 推送卡住/超时 | 网络问题 | 试 `git config --global http.proxy` 或换 SSH、换时段 |
